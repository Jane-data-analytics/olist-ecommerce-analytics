# 🇧🇷 Brazilian E-Commerce Analytics | Olist

### End-to-End Data Analytics Project

An end-to-end e-commerce data analytics project using **Microsoft Excel, MySQL, and Power BI** to explore Brazilian e-commerce data, understand customer purchasing behaviour, and analyze sales and order performance.

---

## 📌 Project Overview

This project analyzes the Brazilian E-Commerce Public Dataset by Olist. It explores order transactions, customers, products, sellers, payments, customer reviews, and delivery information to generate meaningful business insights.

The goal is to transform raw e-commerce data into actionable insights through data preparation, exploratory data analysis, SQL analysis, and interactive Power BI visualizations.

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data cleaning, data preparation, Pivot Tables, and exploratory data analysis.
- **MySQL** – SQL querying, data quality checks, data analysis, and business insight generation.
- **Power BI** – Data modelling, interactive dashboards, and data visualization.

## 📐 Business Metric Definitions

- **Item Revenue:** Sum of product prices from order items.
- **Freight Value:** Sum of shipping charges from order items.
- **Total Payment Value:** Sum of payment values recorded in the payment table.
- **Average Order Value (AOV):** Total payment value divided by the number of distinct orders.
- **Repeat Customer:** A customer who placed more than one distinct order in the dataset.
