
# 📈 Power BI Dashboard – Brazilian E-Commerce

This folder contains the Power BI dashboard developed to analyze the Brazilian E-Commerce (Olist) dataset and present key business insights through interactive visualizations.

## 📁 Project File

`Ecommerce Analysis.pbix`

## 📊 Dashboard Analysis

- Overall sales and order performance
- Customer purchasing behaviour
- Monthly sales trends
- Product category performance
- Payment method distribution
- Order status analysis
- Seller performance
- Delivery performance

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Interactive Visualizations

## 🎯 Key Objectives

- Monitor important business KPIs.
- Identify sales and order trends.
- Understand customer purchasing patterns.
- Evaluate product and seller performance.
- Support data-driven business decisions.
