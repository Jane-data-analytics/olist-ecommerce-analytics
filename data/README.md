
# 📂 Dataset – Brazilian E-Commerce (Olist)

This folder contains the processed dataset used in the Brazilian E-Commerce Analytics project.

## 📊 Dataset File

**Olist_Fact_Orders.csv**

- Combined and processed dataset used for project analysis.
- Used for data exploration and analytical reporting.
- Helps analyze order, customer, payment, and sales-related information.

## 📥 Original Dataset Source

The original dataset is publicly available on Kaggle:

🔗 https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The original dataset contains 9 CSV files:

1. olist_customers_dataset.csv
2. olist_geolocation_dataset.csv
3. olist_order_items_dataset.csv
4. olist_order_payments_dataset.csv
5. olist_order_reviews_dataset.csv
6. olist_orders_dataset.csv
7. olist_products_dataset.csv
8. olist_sellers_dataset.csv
9. product_category_name_translation.csv

## 🛠️ Usage

Download the original dataset from Kaggle to reproduce the complete SQL analysis.

The processed `Olist_Fact_Orders.csv` file is provided here as a reference dataset.
