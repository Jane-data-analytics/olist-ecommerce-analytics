
# 📊 Excel Data Analysis – Brazilian E-Commerce

This folder contains the Excel workbook used for data preparation, exploration, and analysis of the Brazilian E-Commerce (Olist) dataset.

## 📁 Project File

`Olist_Ecommerce_Analytics_Project_Excel.xlsx`

## 🔍 Analysis Performed

- Dataset inspection and understanding
- Data cleaning and preparation
- Handling missing values
- Data formatting and organization
- Exploratory Data Analysis (EDA)
- Pivot Table analysis
- Sales and order analysis
- Customer and product analysis

## 🛠️ Tools & Features

- Microsoft Excel
- Pivot Tables
- Sorting and Filtering
- Excel Functions
- Data Formatting
- Exploratory Data Analysis

## 🎯 Objective

To prepare and explore the e-commerce dataset in Excel and identify useful business insights before performing advanced SQL and Power BI analysis.

## 📝 Note

This workbook focuses on data preparation and exploratory analysis. The interactive dashboard is presented separately in the Power BI section.
