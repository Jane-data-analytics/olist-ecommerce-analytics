
# 🗄️ SQL Analysis – Brazilian E-Commerce

This folder contains SQL queries used to analyze the Brazilian E-Commerce (Olist) dataset using MySQL.

## 🔍 Analysis Performed

1. Database and table structure inspection
2. NULL value analysis
3. Duplicate record checks
4. Geolocation data cleaning
5. Order date validation
6. Customer analysis
7. Order status analysis
8. Payment method analysis
9. Monthly sales and order trends
10. Product category performance
11. Top-selling products
12. Seller performance analysis
13. State-wise order analysis
14. Average delivery time analysis

## 🛠️ Tools Used

- MySQL
- SQL queries
- Aggregate functions
- Joins
- Subqueries
- Date functions
- Data cleaning techniques

## 📁 SQL File

`Olist_Ecommerce_Analysis.sql`

Contains the SQL queries used for data validation, cleaning, KPI calculations, and business analysis.

## ▶️ How to Use

1. Download the original Olist dataset from Kaggle.
2. Import the required CSV files into MySQL.
3. Create the database and tables.
4. Open `Olist_Ecommerce_Analysis.sql`.
5. Execute the queries in sequence.

## 📊 Project Objective

To analyze e-commerce performance, customer purchasing behaviour, payment patterns, product sales, and delivery performance using SQL.
